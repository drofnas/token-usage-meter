MAIN UI PROMPT

Use case: ui-mockup
Asset type: high-fidelity flat screen mockup for an ESP32 CYD 2.8-inch touchscreen usage meter.
Primary request: Design a clear, compact main screen showing Claude and Codex subscription limits, with each provider's 5-hour and weekly quota remaining. This is one flat landscape screen, designed for exactly 320 x 240 logical pixels, rendered at a clean 5x enlargement (1600 x 1200). Edge-to-edge UI, with no device bezel, no desk, no perspective and no surrounding poster.
Style: implementable embedded-device UI, crisp readable compact sans-serif typography, simple flat rectangles, minimal icons, no gradients or shadows. Inspired by the existing meter's dark background, pale text and cyan gauges, refreshed for two providers. No charts, daily history, token totals or decorative artwork.
Color palette: background #101820; primary text #F3F6F7; secondary text #AAB8C2; track #324450; Claude accent muted warm orange #D99A78; Codex accent bright cyan #63DFC1. Text and labels remain very high contrast.
Layout, stated in native 320 x 240 logical pixels:
- Compact header from y=0 to 35: left-aligned "USAGE", then small "REMAINING". On the right a simple battery icon with "72%" and a simple gear in a 40 x 36 touch area. Gear opens settings.
- Two provider sections stacked vertically, with a fine divider at y=135. Claude section from y=40 to 128, Codex from y=141 to 230. Outer horizontal margin 12. No card borders or oversized rounded containers.
- Each provider heading is a prominent uppercase name in its accent color.
- Below each heading, two equal columns separated by 16 logical pixels: left labeled "5HR LIMIT", right labeled "WEEKLY".
- Each column has a large percentage, a thin horizontal gauge proportional to remaining capacity, and a short legible reset countdown. Four numbers must be equally prominent. Number text about 27 logical pixels high; label 10 pixels; reset text 9 pixels. Every component must fit the actual 320 x 240 grid.
Exact visible UI text:
Header: "USAGE", "REMAINING", "72%".
First provider: "CLAUDE".
Claude left: "5HR LIMIT", "72%", "Reset 2h 14m"; gauge 72% full.
Claude right: "WEEKLY", "38%", "Reset 3d 8h"; gauge 38% full.
Second provider: "CODEX".
Codex left: "5HR LIMIT", "85%", "Reset 4h 10m"; gauge 85% full.
Codex right: "WEEKLY", "64%", "Reset 5d 2h"; gauge 64% full.
Constraints: all example numbers are synthetic. Render exact readable text; no extra labels, annotations, captions, fake logos or plan names. Flat rectangular screen in strict 4:3 aspect ratio. Both providers fully visible at once. Keep the design realistic for a low-resolution small touchscreen. Do not add bottom navigation.
