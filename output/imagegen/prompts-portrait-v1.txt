CYD Claude + Codex usage meter — portrait UI mockups

Generation method: built-in image_gen tool, adapting the earlier landscape mockups.
Target device: 240 x 320, 2.8-inch CYD in portrait orientation.
Generated PNGs: 1086 x 1448, exactly 3:4, enlarged concept previews rather than native firmware renders.
Data: synthetic examples; all quota percentages represent capacity remaining.

Intended behavior for implementation:
- Default presentation is portrait.
- The gear opens settings; back returns to usage.
- Claude and Codex can each be enabled or disabled on-device.
- Each provider's 5-hour gauge can be hidden independently.
- A provider's weekly gauge expands across its section when its 5-hour gauge is hidden.
- Supported windows come from provider data; absent windows must not display fake values. Do not hard-code window availability solely by subscription tier.
- Rotation offers 0, 90, 180 and 270 degrees; 90 is selected in this mockup, relative to the current firmware's landscape baseline.
- Settings apply immediately and persist across restarts.
- Firmware, collectors, live integration and hardware readability/touch testing are not implemented or verified by these mockups.
